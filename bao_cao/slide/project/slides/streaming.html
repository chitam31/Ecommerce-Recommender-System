Three streaming jobs run continuously. The first lands every event in bronze. The second computes the trending table: a fifteen-minute window sliding every minute, merged into gold every twenty seconds. The third writes the impression log used by the A/B test. One design point: windows are keyed on the Kafka timestamp, not the original event time, because the replayed data is from 2015 and live clicks are from 2026.
