FeatureHow the project uses it
MERGEUpserts of recommendation lists, trending windows and impressions; surplus ranks deleted

20 / 28

Every Delta Lake requirement of the specification is used for a real purpose. MERGE makes every writer idempotent. Time travel supports reproducibility. Schema evolution produces model version 2. Change Data Feed lets the A/B job read only new impressions. And because streams and maintenance write the same tables, optimistic concurrency had to be handled with an explicit retry.
