The cluster has six laboratory machines on a ZeroTier network. The master runs the NameNode, the Spark Master, all drivers and Airflow. Five workers give 34 cores and 13 gigabytes of executor memory. Each machine has only 7 gigabytes of RAM and is shared with other groups, so every memory setting was sized from measurements.
