We use the RetailRocket dataset: almost 2.9 million events over 139 days. The matrix is extremely sparse, 3.3 times ten to the minus five, and most visitors appear only once, which shapes every result later. A producer replays the log through Kafka, one day in thirty seconds, and adds about five percent synthetic new users so that cold start can be exercised. Evaluation uses a temporal split: the last month is the test set.
